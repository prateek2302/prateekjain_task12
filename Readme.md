# JavaScript - Compound Interest Calculation

A pure JavaScript implementation to compute compound interest from static values using mathematical operators and variables.

## Formula Used
- **Formula**: `A = P * (1 + r/n)^(n*t)`
- **Variables**:
  - `P` (Principal): 10,000
  - `r` (Rate of Interest): 0.08 (8%)
  - `n` (Compounding frequency per year): 1
  - `t` (Time in years): 3

## Files Included
- `index.html`: Web page shell connecting CSS and JavaScript.
- `style.css`: Presentation card layout.
- `script.js`: Mathematical logic and `console.log()` execution.
- `Readme.md`: Documentation.
